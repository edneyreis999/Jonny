# VisuStella MZ - Message Core

Plugin Tier 1 para RPG Maker MZ que estende o sistema de mensagens com text codes avançados, auto-color, macros, word wrap, choice handling expandido e suporte a multi-idioma.

## Principais Áreas

- **conceitos/**: Visão geral do plugin e sistema de troca de idioma (Text Language Switching)
- **text-codes/**: Referência completa de todos os text codes - default MZ, hard-coded (global/message/choice/name-window/battle), customizáveis, random text pool
- **comandos/**: Plugin Commands - Message, Choice, Picture, Select
- **parametros/**: Plugin Parameters - General Settings, Auto-Color, Custom Font Manager, Text Code Actions/Replacements, Macros, Language, Text Speed, Word Wrap
- **referencia/**: Glossário e notas de compatibilidade
