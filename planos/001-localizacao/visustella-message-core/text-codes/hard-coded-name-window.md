# Name Window-Only Text Codes

Text codes exclusivos da Name Window do VisuStella Message Core. Funcionam apenas dentro do campo de nome (Name Box) do Show Text event command.

---

## Position

Controlam a posicao horizontal da name box em relacao a message window.

| Text Code | Effect |
|-----------|--------|
| `<Left>` | Name box posicionada a esquerda |
| `<Center>` | Name box centralizada |
| `<Right>` | Name box posicionada a direita |
| `<Position: x>` | Posicao numerica de 0 a 10 relativa a tela |

---

## Background Type

Mudam o tipo de fundo da name window.

| Text Code | Effect |
|-----------|--------|
| `\NormalBG` | Fundo normal (opaco com borda) |
| `\DimBG` | Fundo dim (semi-transparente escuro) |
| `\TransparentBG` | Fundo transparente |
