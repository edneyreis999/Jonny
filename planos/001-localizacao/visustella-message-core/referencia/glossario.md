# Glossario - VisuStella Message Core

Termos e conceitos do plugin VisuStella Message Core.

| Termo | Definicao |
|-------|-----------|
| Text Code | Codigo especial iniciado com `\` ou `<>` usado em Show Text para exibir conteudo que texto normal nao consegue produzir |
| Text Code Action | Text code que executa uma acao (JS ou Common Event) ao aparecer na mensagem |
| Text Code Replacement | Text code que se substitui por texto (string ou resultado de expressao JS) |
| Text Macro | Substituicao no formato `[MacroName]` sem argumentos condicionais. Expande para texto pre-definido |
| Word Wrap | Propriedade que faz texto overflow wrap automaticamente para a proxima linha |
| Auto-Color | Sistema que colore automaticamente entradas do database e keywords detectadas no texto |
| Name Box Window | Janela que mostra o nome do speaker acima da message window |
| Choice Window | Janela de selecao de opcoes do comando Show Choices |
| Message Window | Janela principal de texto do sistema de mensagens |
| Plugin Command | Comando de evento que chama uma funcionalidade do plugin diretamente |
| Plugin Parameter | Configuracao ajustavel do plugin acessivel pelo Plugin Manager |
| Extension Plugin | Plugin que requer este plugin como Parent Plugin para funcionar |
| Tier | Nivel hierarquico do plugin. Este e Tier 1 (deve ser colocado abaixo de plugins de tier menor) |
| Fast Forward Key | Tecla configurada para acelerar a exibicao de mensagens |
| Text Delay | Frames de espera entre cada caractere desenhado na mensagem |
| Dim Background | Fundo semi-transparente escuro da janela de mensagem |
| Face Graphic | Imagem de rosto do personagem exibida na message window |
| CSV/TSV | Formatos de arquivo para traducoes. CSV usa semicolon (;) como separator, TSV usa tab |
| Language Switching | Sistema de troca de idioma do jogo (manual, nao automatico) |
| Custom Font Manager | Registro de fonts customizadas para uso no jogo, gerenciado pelo Core Engine |
